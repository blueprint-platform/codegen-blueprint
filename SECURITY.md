# Security policy

Report vulnerabilities privately through [GitHub vulnerability reporting](https://github.com/blueprint-platform/codegen-blueprint/security/advisories/new) when available, or email [baris.sayli@gmail.com](mailto:baris.sayli@gmail.com). Include the version or commit, platform, affected input, impact and the smallest safe reproduction. Keep exploit material out of public issues.

Security reports can concern the CLI, generator, bundled templates, generated dependency selections or repository automation. The generator’s [delivery boundary](docs/architecture/executable-architecture-contract.md#delivery-and-reproducibility) leaves runtime configuration, dependency updates and deployment to the consumer.

Codegen Blueprint 2.0 is the active development and maintenance line.

The maintainer triages privately and coordinates disclosure and fixes based on impact.
