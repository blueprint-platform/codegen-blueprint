# Generated project walkthroughs

These README snapshots are generated by the 2.0 snapshot CLI with Boot 4.2, Java 25, strict guardrails and the basic sample.

- [Standard layout](standard.md)
- [Hexagonal layout](hexagonal.md)

Regenerate them with the packaged JAR using [the snapshot script](../../scripts/refresh-generated-readmes.sh). The script uses a controlled connection failure to select the bundled patch and checks the resolution source. The [quickstart](../quickstart.md) uses the normal resolver, which can select the Central patch or the bundled reference.
